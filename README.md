# Northstar Daily

A modern editorial news website starter built with Next.js, TypeScript, and Tailwind CSS.

## Features
- Modern homepage with breaking-news banner
- Featured stories and category coverage
- Full article pages
- Search page for filtering by keyword
- Responsive editorial-inspired layout

## Tech stack
- Next.js 14
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure
- `app/` - routing and page files
- `components/` - reusable UI blocks
- `lib/data.ts` - sample news data

## Notes
This starter is designed for a clean editorial/news style and is ready to be connected to a CMS or news API later.
